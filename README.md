# Panel de Vida

Web app personal (PWA) para iPhone con dos pantallas: **Hoy** (calendario, tareas, emails, resumen) y **Entreno** (Hevy, macros, progreso).

## Desarrollo

```bash
npm install
npm run dev
```

## Variables de entorno

- `APP_PASSWORD`: contraseña para entrar en la app. Si no existe, la app queda abierta (solo para desarrollo local).

## Estado

Fase 1: interfaz con datos de ejemplo, login e instalación en el iPhone. Las tareas tachadas y las comidas se guardan en el propio dispositivo de momento.
